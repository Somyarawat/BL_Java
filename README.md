# Bridgelabz Training - Java Programming

## Overview

This repository contains all the Java programming assignments, practice problems, and learning modules completed during the BridgeLabz Training Program.

The purpose of this repository is to track progress, organize solutions, and maintain code developed while learning core and advanced Java concepts.

---

## Technologies Used

* Core Programming
* Object-Oriented Programming (OOP)
* Collections Framework
* Exception Handling
* File Handling
* Multithreading
* Java 8 Features (Lambda Expressions, Streams, Functional Interfaces)
* Design Patterns
* Data Structures and Algorithms
* Git and GitHub

---

## Repository Structure

The repository is organized into multiple branches, with each branch dedicated to a specific training module or topic.

### Branches

1. Branch 1 - Core Programming
2. Branch 2 - Object-Oriented Programming
3. Branch 3 - Data Structure And Algorithms
4. Branch 4 - Advance Java Programming
5. Branch 5 - Design Modeling
6. Branch 6 - IO Programming And MultiThreading
7. Branch 7 - Review
8. Branch 8 - Main (Default)

> Each branch contains source code, practice exercises, and assignments related to its respective topic.
